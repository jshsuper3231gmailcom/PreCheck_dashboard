 # 첨부 파일 설명 
 - 서버별 디스크 사용률을 나타네는 도넛차트, 나머지 부분은 고려하지 않아도됨
# 문제 
- 서버가 여러게로 늘어날경우 도넛차트의 수도 늘어나기 때문에 화면에서 차지하는 비율이 너무 커질 우려가 있음
- 디스크 사용률 뿐만 아니라 메모리 사용률도 서버별로 표시해야함
# 목표
- 차트의 종류를 변경, 예 도넛차트에서 바차트로 표기(추천 필요)
- 한서버의 정보를 표시하는 크기가 크지 않음, 따라서 서버의 수가 늘어도 도넛차트 처럼 화면에서 차지하는 공간이 크지 않음
- 한 차트에 서버명 사용률, 임계치 표시, 임계치 수치, 정상/에러/경고 여부
- 차트의 색과 폰트는 첨부파일과 최대한 유사하게 유지
# 조건
- 클로드 코드로 바이브 코딩을 하기위한 디자인 가이드 작성, 샘플 이미지 작성
- 모호하거나 결정하지 않은 사항은 반드시 물어볼껏
